Codice is an index of Mexican tax, the SAT's rules and the law they rest on, made for AI to read. When a model gets a fiscal question it looks the answer up in Codice and tells you where it came from.

It started inside [Transitive](https://transitive.app), the fiscal automation pipeline we build for freight forwarders, and now it's public too. I designed and built it, with a lot of feedback from the accountants we work with.

## Confidently wrong

At Transitive we added an agent to explain why an invoice got rejected and what to do about it. The accountants reading it are really good, and the answers were wrong, outdated and full of jargon. Something like:

> The rejection stems from the RegimenFiscalReceptor not being compatible with the UsoCFDI, per the applicable catalog.

What a terrible, terrible message haha. We were working with a lot of pretty important companies and their accountants, and this wasn't doing anyone any favors. The model was answering from memory, with rules that had already changed and regimes mixed up.

## Answers with sources

We tried small embeddings first and then the SAT's documents as markdown references, and the models still did whatever they wanted. What ended up working was an index, every rule and article is its own passage with its source, and the model searches it, reads it and quotes it.

Since the model gets the actual passage, it can put it in whatever words its users like and still be right, which took care of the jargon.

## Keeping it accurate

An index only helps if it's current, and rules change all the time in accounting, I've seen accountants find out about a change years later. Everything comes straight from the SAT, refreshed every week, and each passage carries the dates it's valid so a model can tell the current rule from an old one.

It also only helps if models actually use it. Opus 5.5 throws about 250 questions at Codice over and over and checks the answers against the real documents, and what it catches the most is our test agents answering from memory anyway, a harness problem we keep chasing.

## Built for your AI

We built a whole agent on top of Codice at some point and dropped it, people already have an AI they like talking to, so Codice ships as an MCP server and an API that plug into that one. That means you should pretty much never have to open it, even as a developer the only reason to go in is to grab a key.

## Where it is now

Codice is in open beta, and thanks to Cloudflare being so generous it's free while we figure out costs and volume. I'd like to keep it that way, so nobody needs yet another AI subscription to get their taxes right.

Setup is next, right now it takes a bit of technical knowledge and it really shouldn't.
